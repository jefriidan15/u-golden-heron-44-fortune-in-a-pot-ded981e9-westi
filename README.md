A kind, funny fortune for a houseplant, written as a prediction for the plant
on the windowsill — specific to this window, warm to plant and keeper, with the
surprise saved for the last few words. The program writes one line (107 characters) to
`/output/entry.txt`:

> The sun through this window has chosen you: a new leaf by Thursday, and a human who finally waters on time.

## Run

```sh
node main.ts
```
